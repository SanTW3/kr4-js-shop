# Контрольная работа №4 — ShopProject

Тема: «JavaScript: интерактивность, DOM, события, формы и валидация».
Основа: адаптивный магазин `kr3-responsive-shop` (КР №3). Выполнено по практическим занятиям №15–18.

ФИО: **укажите перед сдачей**. Группа: **укажите перед сдачей**.
Название репозитория: **kr4-js-shop**.

## Запуск

Откройте `index.html` в браузере. Для стабильного сохранения корзины между страницами рекомендуется локальный сервер из папки проекта:

```sh
python3 -m http.server 8000
```

Затем откройте http://localhost:8000. Установка npm-пакетов не нужна.

## Структура

- `index.html` — главная страница из КР №3.
- `catalog.html` — интерактивный каталог.
- `product.html?id=1` — подробности выбранного товара; неизвестный ID выводит сообщение.
- `cart.html` — корзина, количество и итоговая сумма.
- `order.html` — учебная форма заявки.
- `contacts.html` — контакты.
- `css/style.css`, `css/responsive.css` — оформление и адаптивность из КР №3.
- `css/interactive.css` — оформление интерактивных элементов.
- `js/data.js` — 10 товаров с полями id, title, category, price, isAvailable, rating, description; форматирование цены и поиск по ID.
- `js/catalog.js` — создание карточек, поиск, фильтры, сортировка и страница товара.
- `js/cart.js` — состояние корзины, localStorage, изменение количества, удаление и расчёты.
- `js/validation.js` — проверка заявки и сообщения об ошибках.
- `js/main.js` — меню, кнопки главной страницы и инициализация счётчика.

## Обязательная часть

Карточки создаются из массива через createElement, append, classList и textContent. Скрипты подключены с defer. Поиск по названию не учитывает регистр и внешние пробелы. Фильтр категории и наличия совместим с поиском. Сортировка по возрастанию/убыванию цены или названию работает с новым массивом, не изменяя исходные данные. Есть сброс фильтров и пустое состояние.

Форма проверяет имя (от 2 символов), email, телефон (10–15 цифр, допустимы пробелы, скобки, дефис и плюс), обязательное согласие. Комментарий необязателен. Ошибки выводятся рядом с полями и связаны через aria-describedby; фокус переводится к первой ошибке. Успех — только имитация: сервера и отправки персональных данных нет.

Пользовательские строки не вставляются через innerHTML. События подключены через addEventListener; alert не используется.

## Самостоятельные расширения

- Корзина: добавление, уменьшение/увеличение количества (до 99), удаление, пустое состояние.
- Сохранение корзины в localStorage, проверка прочитанных данных и обработка недоступного хранилища.
- Расчёт суммы и счётчика через reduce.
- Фильтр наличия, блокировка покупки отсутствующего товара.
- Количество результатов и средняя цена найденных товаров.
- Страница товара по параметру URL.
- Расширенная валидация и доступные сообщения.

## Самопроверка в браузере

1. Каталог: 10 карточек. Поиск `lamp` находит Smart Lamp; неизвестное название показывает пустое состояние.
2. Совместите категорию, наличие и сортировку, затем сбросьте фильтры.
3. Добавьте товар дважды, откройте корзину: количество 2, сумма равна двойной цене.
4. Измените количество, удалите товар, перезагрузите страницу и проверьте сохранение.
5. Откройте товар из карточки и попробуйте `product.html?id=999`.
6. Отправьте пустую форму, затем заполните корректно. Ошибки и успех должны появиться на странице.
7. Проверьте меню на узком экране и переходы клавишей Tab.
